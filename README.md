## Struktur Folder (`Source-code/`)

Keseluruhan pengerjaan tugas dibagi ke dalam 5 sub-folder utama:

1. **`eksperimen/`**
   Berisi kode-kode dasar yang digunakan untuk uji coba dan eksperimen selama mempelajari modul:
   - Eksperimen DOM dan Event
   - Diagnosis Error (Debugging)
   - Async Fetch dan State UI

2. **`independent-challenge/`**
   Berisi hasil penyelesaian *independent challenge* yang ada di dalam modul (Kalkulator Harga, FAQ Accordion, Async Data Loader).

3. **`praktikum/`**
   Memuat pengerjaan *Task* utama:
   - **Task 1**: JavaScript Logic Builder
   - **Task 2**: DOM dan Form Controller
   - **Task 3**: Asynchronous JavaScript Data Loader

4. **`homework/` (Interactive Profile Card)**
   Aplikasi profil interaktif yang menampilkan data profil secara asinkron (menggunakan `fetch` API untuk meload file `data/profile.json`). 
   - *Fitur*: Toggle detail, Ubah tema gelap/terang, Tambah/hapus *skill* dengan validasi form (tanpa *input* kosong/terduplikasi).
   - Dilengkapi transisi antarmuka *state handling* (Loading, Success, Empty, Error).

5. **`miniproject/` (Landing Page Interaktif - Inovatech)**
   Pengembangan halaman statis dari Modul 1 menjadi interaktif sepenuhnya tanpa *framework/library*.
   - *Fitur*: Navigasi *mobile*, render daftar layanan secara dinamis dengan DOM (*createElement*), filter kategori, *FAQ Accordion* dengan dukungan aksesibilitas *keyboard*, validasi formulir kontak yang ketat, pergantian *Dark/Light Mode*, dan tombol 'Kembali ke Atas' (*Back to Top*).
